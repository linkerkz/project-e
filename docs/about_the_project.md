# Venty — О проекте

> Все мероприятия города — в одной ленте

---

## Суть продукта

Venty — мобильное приложение для организации и отслеживания мероприятий. Помогает жителям города создавать и развивать локальные комьюнити, быть в курсе событий и активно участвовать в жизни своего города.

Продукт строится вокруг ленты событий (а не скучного каталога) и интерактивной карты — по аналогии с привычным форматом современных социальных сетей.

---

## Проблема

Чтобы найти или организовать мероприятие в городе, сегодня нужно одновременно мониторить 3–5 разных платформ: Instagram, Telegram, 2ГИС, личные знакомства. Специализированные приложения для ивентов оформлены как скучные доски и не удерживают аудиторию.

Итог: чтобы организовать мероприятие с широким охватом, нужен крупный медиаканал. Чтобы найти интересное событие — просмотреть множество источников.

---

## Целевая аудитория

**Организаторы**

- Speaking clubs, спортивные сообщества, образовательные проекты
- Городские инициативы и локальные НКО

**Участники**

- Студенты и молодёжь 18–35 лет
- Люди, ищущие нетворкинг и досуг

---

## Ключевой функционал

- Лента событий — трендовые и рекомендуемые ивенты
- Интерактивная карта мероприятий
- Чат для каждого ивента
- Создание ивентов доступно любому пользователю — без специального статуса
- Публичная веб-страница каждого ивента с превью (название, дата, место, описание, кнопка участия) — без необходимости скачивать приложение

---

## Веб-страница ивента

Каждый ивент получает публичный URL. Когда пользователь делится ссылкой, получатель попадает на читаемую страницу события, а не на экран скачивания приложения. Это снижает барьер входа для новых пользователей и делает каждый ивент самостоятельной единицей контента для распространения в мессенджерах и соцсетях.

---

## Монетизация

Монетизация планируется после 3 000–5 000 MAU в одном городе. До этого — фокус на рост и удержание.

Планируемые модели:

- Реклама внутри приложения
- Подписка для организаторов с расширенными возможностями (аналитика, продвижение ивента, кастомизация) — ориентировочно $10–20/мес.
- Featured placements для городских организаций и брендов

---

## Модерация и открытое создание ивентов

На раннем этапе создавать мероприятия может любой пользователь. Риск спама решается поэтапно:

- **На старте:** лимиты на количество ивентов, блокировки по IP, жалобы пользователей, ручная проверка
- **При росте (3k+ MAU):** рейтинг доверия, верификация через номер телефона, система репутации

Платная подписка как барьер для создания ивентов — крайняя мера, убивает органический рост контента.

---

## Scope MVP

**Входит:**

- Создание ивентов любым пользователем
- Интерактивная карта событий
- Упрощённая лента мероприятий
- Флоу: нашёл ивент → лайкнул → вступил в чат
- Веб-страница каждого ивента с превью
- Базовая модерация: лимиты на создание + блокировки по IP

**Не входит:**

- Алгоритмы рекомендаций в ленте
- Чат со сложными настройками (роли, модерация, боты)
- Продвинутая модерация (актуальна при 3k+ MAU)
