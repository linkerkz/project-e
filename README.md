# Венти

Лента локальных событий вокруг тебя.

# Стек

- React Native — веб, iOS и Android. Единый UI-фреймворк, чтобы не поддерживать разные версии компонентов.
- Supabase — сервис базы данных, чтобы пока не писать отдельный бэкенд.
- NativeWind — стили через классы.
- Zustand — состояние интерфейса, если понадобится.
- React Query — серверное состояние.
- React Hook Form / Zod — формы и валидация.

Возможно, позже понадобится Storybook.
