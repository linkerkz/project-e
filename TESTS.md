# Карта unit-тестов

Файл поддерживается вместе с unit-тестами. На один тест — не больше двух строк: что подаём, что ожидаем, какую проблему ловим.

## `src/shared/lib/publicLink.test.ts`

- `преобразует название в slug`: ввод — строки с пробелами/символами, строка без латиницы, кастомный fallback; вывод — slug или fallback (`activity`/`series`). Проверяет стабильную генерацию безопасной части публичной ссылки для активности и серии.
- `генерирует slug с коротким случайным суффиксом`: ввод — название; вывод — `slug-[a-z0-9]{6}`. Проверяет, что публичные ссылки получают случайный суффикс.
- `генерирует edit token из UUID без дефисов`: ввод отсутствует; вывод — токен `[a-f0-9]{32}`. Проверяет формат секретной ссылки управления.

## `src/shared/lib/publicUrl.test.ts`

- `на нативе берёт канонический origin из env`: ввод — `EXPO_PUBLIC_WEB_URL` + slug; вывод — полный URL. Проверяет рабочую ссылку из шеринга/QR вне веба.
- `завершающий слэш env не даёт двойного слэша`: ввод — env с `/` на конце; вывод — URL без `//`. Проверяет нормализацию origin.
- `на нативе без env отдаёт голый путь`: ввод — пустая env; вывод — `/a/slug`. Проверяет деградацию без падения при ненастроенной env.
- `на вебе берёт origin из адресной строки, а не из env`: ввод — `Platform.OS: web` + window; вывод — origin окна. Проверяет приоритет реального адреса веб-версии.
- `строит ссылку серии по пути /s`: ввод — slug серии; вывод — `origin/s/slug`. Проверяет публичную ссылку серии.
