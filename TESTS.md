# Карта unit-тестов

Файл поддерживается вместе с unit-тестами. На один тест — не больше двух строк: что подаём, что ожидаем, какую проблему ловим.

## `src/entities/activity/utils.test.ts`

- `преобразует название в slug`: ввод — строки с пробелами/символами и строка без латиницы; вывод — slug или `activity`. Проверяет стабильную генерацию безопасной части публичной ссылки.
- `генерирует slug с коротким случайным суффиксом`: ввод — название активности; вывод — `slug-[a-z0-9]{6}`. Проверяет, что публичные ссылки получают случайный суффикс.
- `генерирует edit token из 18 символов`: ввод отсутствует; вывод — токен `[a-z0-9]{18}`. Проверяет формат секретной ссылки управления.
- `нормализует Telegram-хэндл в t.me ссылку`: ввод — `@anna`/`anna`/`t.me/anna`/полная ссылка/пусто/`null`; вывод — `https://t.me/anna` или `""`. Проверяет префилл `chat_url` из Telegram профиля под URL-валидацию.
- `проверяет корректность даты`: ввод — валидный `datetime-local`, `12 мая`, пустая строка; вывод — `true/false`. Проверяет защиту от timestamp-ошибки Supabase до запроса.
- `преобразует дату в ISO, если дата корректна`: ввод — валидная и невалидная дата; вывод — ISO или исходная строка. Проверяет корректный payload для поля `starts_at`.
- `преобразует дату с бэка в значение для datetime-local`: ввод — дата с timezone и мусорная строка; вывод — `YYYY-MM-DDTHH:mm` или исходная строка. Проверяет отображение даты на странице управления.
- `возвращает следующий статус активности`: ввод — `active`/`cancelled`; вывод — обратный статус. Проверяет логику отмены и возврата активности.
- `считает остаток мест из capacity`: ввод — `capacity`/`going` в трёх режимах (`null`, есть места, мест нет); вывод — `kind` `unlimited`/`available`+`left`/`full`. Проверяет расчёт остатка мест для страницы ивента.

## `src/entities/activity/local.test.ts`

- `добавляет и убирает slug при повторном тоггле`: ввод — двойной `toggleLike` одного slug; вывод — `[slug]`, затем `[]`. Проверяет, что повторный лайк снимает отметку.
- `тоггл идемпотентен: один slug не дублируется`: ввод — лайки разных slug; вывод — список без дублей в порядке добавления. Проверяет device-local состояние лайков.
- `повторное добавление того же slug не дублирует запись`: ввод — двойной `addMyActivity` одной активности; вывод — список длины 1. Проверяет дедуп локального списка «Мои ивенты».

## `src/entities/activity/schemas.test.ts`

- `чистит пустые необязательные поля в null`: ввод — форма создания с пустыми описанием/местом/лимитом/обложкой/чатом; вывод — `null` в этих полях. Проверяет контракт чистки, на который опирается маппер.
- `приводит capacity к положительному числу`: ввод — `capacity: "12"`; вывод — `12`. Проверяет coerce строкового лимита в число.
- `требует название, город и корректную дату`: ввод — пустые название/город и мусорная дата; вывод — `success: false`. Проверяет обязательные поля и защиту от timestamp-ошибки.
- `отклоняет некорректную ссылку на обложку`: ввод — `cover_url` не-URL; вывод — `success: false`. Проверяет валидацию ссылки обложки.
- `отклоняет некорректную ссылку на чат`: ввод — `chat_url` не-URL; вывод — `success: false`. Проверяет валидацию ссылки на чат.
- `в форме обновления добавляет статус`: ввод — статус `cancelled` и неизвестный `deleted`; вывод — `true`/`false`. Проверяет расширение схемы статусом.

## `src/entities/activity/mappers.test.ts`

- `преобразует форму создания в payload для API`: ввод — провалидированная форма с `null` в необязательных полях; вывод — `null`, ISO-дата, `slug`, `edit_token`, `active`. Проверяет payload создания (пустые строки в `null` чистит схема).
- `сохраняет заполненные необязательные поля при создании`: ввод — форма с описанием, местом, лимитом, обложкой и чатом; вывод — те же значения. Проверяет, что маппер не затирает введённые данные.
- `преобразует форму обновления в payload для API`: ввод — провалидированная форма редактирования с `null` в необязательных полях; вывод — `null`, ISO-дата и статус. Проверяет payload сохранения активности.
- `преобразует null chat_url в пустую строку для формы управления`: ввод — активность с `chat_url: null`; вывод — `""`. Проверяет префилл формы управления пустым полем чата.
- `сохраняет заполненный chat_url в форме управления`: ввод — активность с `chat_url`; вывод — та же ссылка. Проверяет префилл формы управления заданным чатом.

- `сохраняет заполненные необязательные поля`: ввод — форма с Telegram; вывод — те же значения и `status: going`. Проверяет, что данные участника не теряются, а статус всегда «иду».

## `src/entities/participant/schemas.test.ts`

- `принимает отклик с обязательным именем и статусом «иду»`: ввод — `name` + `status: going`; вывод — `going`, пустой Telegram. Проверяет минимальную валидную форму отклика.
- `требует непустое имя`: ввод — имя из пробелов; вывод — `success: false`. Проверяет обязательность имени.
- `разрешает только статус «иду»`: ввод — `status: maybe`; вывод — `success: false`. Проверяет литерал статуса после сведения к «иду».

## `src/entities/profile/schemas.test.ts`

- `пустые текстовые поля и соц.ссылки превращает в null`: ввод — форма с пустыми городом, фото и всеми соцсетями; вывод — `null` в этих полях, `categories` по умолчанию `[]`. Проверяет чистку пустых строк перед сохранением профиля.
- `сохраняет заполненные поля и интересы`: ввод — заполненные город/фото/интересы/Telegram; вывод — те же значения, незаполненные соцсети `null`. Проверяет, что введённые данные не теряются.
- `принимает локальный URI фото и отклоняет пустое имя`: ввод — локальный `file://` URI фото и имя из пробелов; вывод — `true` для фото, `false` для имени. Проверяет, что device-URI фото не отклоняется, а имя обязательно.

## `src/entities/profile/mappers.test.ts`

- `null в полях профиля превращает в пустую строку для формы`: ввод — профиль с `null` в городе/фото/соцсетях; вывод — пустые строки. Проверяет префилл формы редактирования из хранилища.
- `сохраняет заполненные поля и не тащит дату регистрации`: ввод — заполненный профиль с `registeredAt`; вывод — те же значения без `registeredAt`. Проверяет, что дата регистрации не попадает в форму.

## `src/entities/profile/utils.test.ts`

## `src/shared/errors/getRussianErrorMessage.test.ts`

- `переводит известные технические ошибки`: ввод — timestamp/network ошибки; вывод — русские сообщения. Проверяет, что технические backend/browser ошибки не попадают в UI.
- `возвращает fallback для неизвестной ошибки`: ввод — неизвестная Error и не-Error значение; вывод — fallback. Проверяет безопасное русское сообщение для любых неожиданных ошибок.

## `src/shared/lib/shareActivity.test.ts`

- `успешный шеринг возвращает kind «shared»`: ввод — `Share.share` резолвится; вывод — `{ kind: "shared" }`. Проверяет открытие системного листа на нативе.
- `отмену листа (AbortError) не считает ошибкой`: ввод — `Share.share` бросает `AbortError`; вывод — `{ kind: "shared" }`. Проверяет, что отмена листа не показывается как ошибка.
- `прочую ошибку отдаёт с русским сообщением`: ввод — `Share.share` бросает обычную ошибку; вывод — `{ kind: "error" }` с русским текстом. Проверяет, что сырые сообщения не утекают в UI.
