# Карта unit-тестов

Файл поддерживается вместе с unit-тестами. На один тест — не больше двух строк: что подаём, что ожидаем, какую проблему ловим.

## `src/entities/activity/utils.test.ts`

- `преобразует название в slug`: ввод — строки с пробелами/символами и строка без латиницы; вывод — slug или `activity`. Проверяет стабильную генерацию безопасной части публичной ссылки.
- `генерирует slug с коротким случайным суффиксом`: ввод — название активности; вывод — `slug-[a-z0-9]{6}`. Проверяет, что публичные ссылки получают случайный суффикс.
- `генерирует edit token из 18 символов`: ввод отсутствует; вывод — токен `[a-z0-9]{18}`. Проверяет формат секретной ссылки управления.
- `проверяет корректность даты`: ввод — валидный `datetime-local`, `12 мая`, пустая строка; вывод — `true/false`. Проверяет защиту от timestamp-ошибки Supabase до запроса.
- `преобразует дату в ISO, если дата корректна`: ввод — валидная и невалидная дата; вывод — ISO или исходная строка. Проверяет корректный payload для поля `starts_at`.
- `преобразует дату с бэка в значение для datetime-local`: ввод — дата с timezone и мусорная строка; вывод — `YYYY-MM-DDTHH:mm` или исходная строка. Проверяет отображение даты на странице управления.
- `возвращает следующий статус активности`: ввод — `active`/`cancelled`; вывод — обратный статус. Проверяет логику отмены и возврата активности.

## `src/entities/activity/mappers.test.ts`

- `преобразует форму создания в payload для API`: ввод — форма с пустыми необязательными полями; вывод — `null`, ISO-дата, `slug`, `edit_token`, `active`. Проверяет payload создания без сырых пустых строк.
- `сохраняет заполненные необязательные поля при создании`: ввод — форма с описанием, местом, лимитом и обложкой; вывод — те же значения. Проверяет, что маппер не затирает введённые данные.
- `преобразует форму обновления в payload для API`: ввод — форма редактирования с пустыми необязательными полями; вывод — `null`, ISO-дата и статус. Проверяет payload сохранения активности.

## `src/entities/participant/utils.test.ts`

- `возвращает русский текст статуса`: ввод — `going`, `maybe`, `cant`, неизвестный статус; вывод — русские подписи или исходная строка. Проверяет понятное отображение статусов в UI.
- `считает участников по статусу`: ввод — список участников и статус; вывод — количество совпадений. Проверяет корректные счётчики публичной страницы.
- `возвращает статистику участников`: ввод — список участников; вывод — объект `{ going, maybe, cant }`. Проверяет агрегированную статистику откликов.

## `src/entities/participant/mappers.test.ts`

- `преобразует форму отклика в payload для API`: ввод — форма с пустыми Telegram/comment; вывод — `null` и `activity_id`. Проверяет payload отклика без пустых строк.
- `сохраняет заполненные необязательные поля`: ввод — форма с Telegram/comment; вывод — те же значения. Проверяет, что данные участника не теряются.

## `src/shared/errors/getRussianErrorMessage.test.ts`

- `переводит известные технические ошибки`: ввод — timestamp/network ошибки; вывод — русские сообщения. Проверяет, что технические backend/browser ошибки не попадают в UI.
- `возвращает fallback для неизвестной ошибки`: ввод — неизвестная Error и не-Error значение; вывод — fallback. Проверяет безопасное русское сообщение для любых неожиданных ошибок.
